# Publishing checklist

Not yet published. Source: https://github.com/thejambi/BrewSession-Pebble

## First publish

From the project root, after the sanity list below:

```
pebble publish --non-interactive --no-gif-all-platforms --is-published \
  --name "BrewSession" --version 1.0.0 \
  --description "$(cat store/description.txt)" \
  --source "https://github.com/thejambi/BrewSession-Pebble" \
  --category "Tools & Utilities" \
  --icon-small store/icon_small_48.png \
  --icon-large store/icon_large_144.png \
  --screenshots store/screenshots/*.png \
  --release-notes "First release: custom steep times, felt pour countdown, infusion tracking with ask-on-commit increments, recents as presets, and an alarm that survives the app being closed."
```

After it succeeds, record the appstore URL/app ID here (Berean's checklist
keeps it at the top).

## Releasing an update

1. Bump `version` in `package.json` AND the version string in
   `src/c/win_about.c` (it's drawn by hand there).
2. `pebble clean && pebble build` — clean matters: the version is baked at
   configure time, so an incremental build ships the OLD version label
   inside the pbw.
3. `pebble publish --non-interactive --no-gif-all-platforms --is-published
   --release-notes "..."`
   Do NOT pass `--screenshots` unless screenshots actually changed — the
   store keeps the existing set. When they did change, add
   `--screenshots store/screenshots/*.png`.

Screenshots must be exactly the platform's resolution (all verified exact
for this set — captured with `pebble screenshot`, which has no bezel).

## Artifact

`pebble build` produces the multi-platform bundle at
`build/BrewSession.pbw` (basalt, chalk, diorite, emery, flint, gabbro).

## Store assets

All generated by `python3 tools/make_store_art.py` (banner + icons; the
banner embeds `store/screenshots/emery_4_steeping.png`) except the
screenshots, captured from the emulators:

- emery (200x228): 6 shots — title, ready, pour, steeping, done, picker.
  Portal limit is usually 5 per platform; they're numbered in preferred
  order, drop from the end.
- basalt (144x168), chalk (180x180), diorite (144x168), flint (144x168),
  gabbro (260x260): 3 each — title, ready, steeping.

## Pre-upload sanity list

- [ ] `pebble build` clean, all six platforms in the memory report
- [ ] Version in `package.json` AND `win_about.c` is what the store shows
- [ ] Fresh-install smoke test on real hardware: new custom time → pour
      countdown ticks → steep → shake dismiss → infusion 2 "+ ?" asks on
      Start → recents show the session
- [ ] Exit mid-steep on hardware; confirm the wakeup relaunches into the
      alarm at the right moment
- [ ] Touch: drag the picker wheel, tap-to-start, tap a menu row

## Known texture

- Emery is emulator-verified end to end and the touch layer is
  wrist-tested on Pebble Time 2. Chalk, gabbro, and the B&W platforms were
  verified in the emulator only.
- The steeping screen's ±5s buttons: Up adds time, Down removes it
  (matches the picker's Up-is-more).
